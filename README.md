## 🚀 Getting Started

### Prerequisites
```bash
# Required software
- Node.js 18+ 
- Python 3.8+
- Git
```

### 🔧 Installation

1. **Clone the repository**
```bash
git clone https://github.com/yourusername/citi-connect.git
cd citi-connect
```

2. **Install frontend dependencies**
```bash
npm install
# or
pnpm install
```

3. **Set up backend**
```bash
cd backend
pip install -r requirements.txt
```

4. **Configure environment variables**
```bash
# Create .env.local file
GEMINI_API_KEY=your_gemini_api_key
PY_BACKEND_URL=http://localhost:5000
voice_API_KEY=your_voice_key
```

5. **Start the development servers**
```bash
# Frontend (Terminal 1)
npm run dev

# Backend (Terminal 2)
cd backend
python app.py
```

6. **Access the application**
```
Frontend: http://localhost:3000
Backend API: http://localhost:5000
```
